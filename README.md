## Short description
Within this folder, three separate folders are present:
- __Data__: Currently empty, but should be filled with the data available at [Zenodo](https://doi.org/10.5281/zenodo.20397152).
- __Figures__: Currently empty, but is used by the scripts to store generated graphs.
- __Scripts__: Folder with all the relevant scripts, named according to chapter and order.

The published scripts have been generated between 2015 and 2020 to support the analyses that were used to write the thesis _Data-driven models and trait-oriented experiments of aquatic macrophytes to support freshwater management_ (available via [this link](http://hdl.handle.net/1854/LU-8661434)). They have been revised for functionality (including reorganisation into a single folder) without changing the underlying analyses. For sure, further optimization to cleaner and more efficient codes is possible (though will not be done by the authors in the near future). Publishing these scripts is considered to increase the transparency of the performed work, rather than claiming to represent the most efficient analysis approach. In this regard, it is also interesting to notice that a time indication is often included per part. It goes without saying that this will differ depending on the available core capacity. Whether more or less time should be provided, can easily be checked for a single part.
